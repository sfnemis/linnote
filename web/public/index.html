Install

Three ways in

Pick the one your distribution uses. Each build is tested on the system it is named after.

🐧 Universal

Fedora, Debian, Ubuntu and the distributions built on them. Detects your system, installs the dependencies, drops in the binary.

curl -fsSL https://linnote.app/install.sh | bash

🔷 Arch Linux (AUR)

Builds from source against your own Qt and OpenSSL, so it keeps working across rolling updates.

yay -S linnote

📦 Flatpak

For immutable systems. LinNote has its own signed repository, so a flatpak update keeps it current. OCR does not work in the sandbox yet.

flatpak install --user --from https://linnote.app/linnote.flatpakref

GNOME users: the global hotkey binds on GNOME since 2.0.1. Nothing to configure by hand any more. Learn more →

See it in action

Explore LinNote's powerful features and beautiful interface

Every page is a mode. Type a keyword on a blank line and the page becomes a calculator, a checklist, a code block, a timer or a markdown document.

01 / CALC

Smart Calculator with variables and functions

Finish a line with an equals sign and the answer lands in place. Variables, functions, percentages, unit and currency conversion on the same line.

02 / LIST

Interactive Checklist Mode

Type list and every new line becomes a checkbox you can tick with the keyboard.

03 / STATS

Built-in Statistical Functions

sum, avg and count read the numbers already on the page. No selecting, no re-typing.

04 / TEXT

Word Count & Text Analysis

Character and word counts for the page you are on, without leaving it.

05 / TIMER

Countdown Timer & Pomodoro

Stopwatch, countdown and Pomodoro live in a page like everything else.

06 / SETUP

First Run Setup Wizard

Theme, currency, hotkey and encryption, chosen once on first launch.

07 / LOCK

Note Encryption with Recovery Key

Lock a page with a password. Since 2.0.0 the content is sealed with AES-256-GCM and a key derived with PBKDF2.

08 / EDITOR

Customizable Editor Settings

Font, size, indentation and paste cleanup, all in one panel.

09 / KEYS

Configurable Keyboard Shortcuts

Every action has a key, and every key can be changed.

10 / ABOUT

Feature-Rich Application

Version, licence and update check, where you expect them.
